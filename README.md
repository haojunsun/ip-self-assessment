# 个人 IP 七维自测

内容一直发，客户却不知道为什么找你？用一套有依据的自测，检查从定位到咨询之间的缺口。

这是一个中文 AI Agent Skill：逐项提问，根据回答与材料评分，最后给出 100 分制报告、得分依据和优先改进动作。

## 能做什么

- 默认一次问一个维度，也支持一次填写完整问卷。
- 7 个维度、20 个检查项，每项 0—5 分。
- 区分具体自述、实际材料、验证与改进记录。
- 未回答的项目保留待评，输出分数区间，不伪造完整总分。
- 输出七维评分、20 项明细、关键缺口和最多 3 项改进动作。
- 支持用同一量表复测，解释分数变化。

## 评分结构

| 维度 | 满分 | 检查重点 |
| --- | ---: | --- |
| 定位 | 15 | 服务对象、问题与帮助范围、表达一致性 |
| 人群 | 15 | 具体场景、真实需求、优先服务对象 |
| 产品 | 15 | 交付物、服务边界、适用条件 |
| 内容 | 15 | 客户问题、可用方法、业务关联 |
| 信任 | 20 | 作品、过程、结果、证据完整性 |
| 咨询路径 | 10 | 服务入口、咨询准备与回应流程 |
| 复盘 | 10 | 数据记录、反馈与改进 |

每项评分：0 = 明确没有；1 = 泛泛表述；2 = 有细节但不完整；3 = 回答完整一致；4 = 有实际使用材料；5 = 有验证、调整和复查记录。完整规则见 [SKILL.md](SKILL.md)。

这是业务准备度量表，不是行业认证，也不预测收入或获客成功率。

## 安装与调用

将本仓库克隆到 Codex 的技能目录。默认目录为用户主目录下的 `.codex/skills`；设置了 `CODEX_HOME` 时使用该目录下的 `skills`。目标目录已有同名 Skill 时先检查差异，不要直接覆盖。

```bash
git clone https://github.com/haojunsun/ip-self-assessment.git ~/.codex/skills/ip-self-assessment
```

在能发现该技能的会话中输入：

```text
$ip-self-assessment 帮我做个人 IP 自测，一次问一个维度，最后根据回答和证据评分。
```

也可以输入：

```text
$ip-self-assessment 一次发我完整问卷，我填完再评分。
```

若当前客户端尚未显示技能，可在新会话检查发现情况，或明确要求助手读取本仓库的 `SKILL.md` 执行。其他支持类似 Skill 结构的助手可按各自安装方式使用；本仓库未逐一测试其兼容性。

## 独立核算脚本

`scripts/score.py` 使用 Python 3 标准库，无需第三方依赖。它只核算评分，不分析自然语言或替代证据判断。

把评分映射 JSON 传入标准输入。键为 `P1–P3`、`A1–A3`、`O1–O3`、`C1–C3`、`T1–T4`、`J1–J2`、`R1–R2`，值为 0—5 的整数；省略或 `null` 表示待评。

```bash
python -X utf8 scripts/score.py < scores.json
```

PowerShell：

```powershell
Get-Content -Raw -Encoding UTF8 scores.json | python -X utf8 scripts/score.py
```

例如输入 `{"P1": 5}`，输出暂评范围 `[5, 100]`、覆盖率 `5%`，最终总分与等级为 `null`。输入全部 20 项且每项 3 分时，总分为 60。脚本只读取标准输入并输出 JSON，不写入答卷文件。

## 数据与验证范围

默认报告留在对话，只有用户要求时才另存。可以使用脱敏材料，不需要提交客户身份或私聊全文。本地核算脚本不联网；向 AI 助手提交的回答与材料按所用客户端的数据规则处理。

已检查 Skill 格式、总分与分级边界、待评区间、关键缺口判定、无效输入和脚本标准输入调用；尚未完成真实业务样本的有效性验证。
